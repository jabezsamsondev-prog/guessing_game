# Guessing Game

A modern, interactive number guessing game built with HTML, CSS, and JavaScript.

## 🎮 Features

- **Multiple Difficulty Levels**:
  - **Easy**: Larger range of numbers, more chances.
  - **Medium**: Balanced challenge.
  - **Hard**: Tight number range, fewer chances.
- **Responsive Design**: Looks great on desktop and mobile.
- **Interactive UI**: Smooth animations, glassmorphism effects, and dynamic feedback.
- **No Time Limit**: Take your time to guess the correct number.

## 🚀 How to Play

1. Select a difficulty level (Easy, Medium, or Hard).
2. Enter your guess in the input field.
3. Receive feedback:
   - "Too High" or "Too Low" hints.
   - Remaining chances are displayed.
4. Try to guess the hidden number before you run out of chances!

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (Vanilla CSS with modern animations)
- **JavaScript** (ES6+)
